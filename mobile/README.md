# Punchbook Pickup (Android first)

Order-ahead pickup app for Punchbook restaurants. Expo / React Native + TypeScript, Expo Router.

Flow: restaurant list → menu → bag & checkout (pickup time, name, mobile, card or JustPay) → live order status with pickup code → My orders.

Restaurants and menus come from the main server (`../restaurants.js` via `/api/pickup/*`). Restaurants manage orders at `/pickup-admin` (New → Preparing → Ready → Collected); the app polls every 5 seconds.

## Run on the Android emulator

```bash
# terminal 1, repo root
npm start                      # server on :3000

# terminal 2
cd mobile
npm install
npx expo run:android           # builds, installs and starts the dev build
```

Debug builds call `http://10.0.2.2:3000` (the emulator's alias for your Mac). On a physical phone, use your Mac's LAN IP:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.20:3000 npx expo run:android
```

Release builds call `https://punchbook.online`, so deploy the server changes before shipping.

## Notes

- Payments use the server's existing card/JustPay adapters, which are simulated unless OnePay credentials are set. Checkout shows a "demo" line; remove it before a real launch.
- No accounts: name, number and recent orders are stored on the device (AsyncStorage).
- `android/` and `ios/` are generated by `npx expo prebuild` and are git-ignored; configure native settings in `app.json`.
